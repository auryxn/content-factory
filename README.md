# Content Factory

> Часть портфолио: [сайт-портфолио](https://auryxn.github.io) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Локальный «контент-завод»: режет длинные видео на короткие ролики под TikTok, накладывает фоновую музыку и ведёт расписание публикаций через веб-дашборд.

## Что это (простыми словами)

Content Factory автоматизирует нарезку длинных видео (например, загруженных видео про выживание/кемпинг) на короткие клипы стандартной длины, которые удобно выкладывать в TikTok.

- **Обработка.** Видео-файлы кладутся в папку `incoming/`. Скрипт `montage.py` режет каждый исходник на куски ровно по 120 секунд (2 минуты — под формат TikTok), при наличии накладывает фоновую мелодию из `assets/` и складывает готовые клипы в `ready/`. Обработанный исходник переносится в `processed/`.
- **Управление.** Веб-дашборд на `http://127.0.0.1:8000` показывает, какие видео ждут обработки и какие клипы уже готовы, позволяет задать аккаунт/описание/хештеги, сгенерировать автоматическое расписание выкладки («Part 1», «Part 2», …) и отметить клипы как «выложено».
- **Планирование.** Каждой нарезке присваивается дата и время публикации: окно с 14:00, до 10 роликов в день, шаг 60 минут. Клипы одного исходного видео группируются вместе.

Для кого: человек, который ведёт TikTok-аккаунт с серийным контентом и хочет массово превращать длинные видео в очередь запланированных коротких постов.

## Возможности (реальные фичи)

- **Нарезка видео** ровно по 120 секунд (`CLIP_SECONDS`) через `ffmpeg` (H.264, AAC, `+faststart`).
- **Наложение фоновой музыки** из `assets/bgm.mp3` (или любого `.mp3/.m4a/.wav/.ogg` в `assets/`) с приглушением до 25% и зацикливанием под длину клипа.
- **Устойчивость к ошибкам:** битый сегмент/конец файла не роняет весь батч — проблемная нарезка пропускается; есть эпсилон-защита от «фантомного» пустого клипа на самом конце.
- **Именование частей:** каждый исходник нумеруется с `part001`, `part002`, … независимо от других видео.
- **Дашборд (FastAPI):**
  - список видео в `incoming/` и кнопка «Обнаружить»;
  - кнопка «Монтировать» — запускает монтаж в фоне (без блокировки браузера);
  - прогресс монтажа в реальном времени (`/api/montage_status`);
  - карточки готовых клипов: превью, аккаунт, описание, хештеги, статус;
  - групповое обновление всех нарезок одного исходника (аккаунт/описание/теги) с автоподстановкой `| Part N`;
  - редактирование отдельного клипа и отметка «Выложено» (`posted`);
  - генерация и пересчёт расписания выкладки (`/api/schedule`);
  - отдача файлов на просмотр и на скачивание.
- **Автоматические значения по умолчанию:** аккаунт `main`, теги `#survival #bushcraft #outdoors #wilderness #survivaltips`, описание `Survival skills you need to know | Part N`.

## Стек

- Python 3 (виртуальное окружение в `.venv/`)
- FastAPI + Uvicorn (веб-дашборд, `server.py`)
- `ffmpeg` / `ffprobe` (нарезка, длительность, наложение звука)
- Хранилище — JSON-файл `jobs.json` (список нарезок и их метаданные)
- Статика/шаблон — `templates/index.html`, `static/`

## Установка и запуск

Требование: установленный в системе `ffmpeg` (и `ffprobe`).

```bash
cd projects/content-factory

# Быстрый запуск (создаст venv и поставит зависимости, если их нет)
./run.sh
# дашборд: http://127.0.0.1:8000
```

`run.sh` при первом запуске создаёт `.venv` и ставит `fastapi uvicorn python-multipart`, затем запускает `server.py`.

### Ручной запуск / монтаж

```bash
# поднять только дашборд
./.venv/bin/python server.py

# или прогнать монтаж из командной строки (режет всё из incoming/)
python3 montage.py
```

### Рабочий процесс

1. Положить видео в `incoming/` (`.mp4 .mov .mkv .avi .webm .m4v`).
2. Открыть дашборд → «Обнаружить» → «Монтировать».
3. Готовые клипы появятся в `ready/`, исходники переедут в `processed/`.
4. Задать аккаунт/описание/хештеги (можно группой), проверить расписание и отмечать клипы как «Выложено».

Основные API-эндпоинты: `/api/state`, `/api/discover`, `/api/montage`, `/api/montage_status`, `/api/update`, `/api/update_group`, `/api/schedule`, `/media/<name>`, `/download/<name>`.

## Структура проекта

```
content-factory/
├── server.py            # FastAPI-дашборд: список, монтаж, карточки, расписание
├── montage.py           # монтаж: нарезка по 120с + фоновая музыка
├── run.sh               # запуск дашборда (создаёт venv при необходимости)
├── jobs.json            # список нарезок и их метаданные (аккаунт, описание, теги, статус, расписание)
├── assets/              # фоновая музыка (bgm.mp3 или первый аудиофайл)
├── incoming/            # новые видео на обработку
├── processed/           # обработанные исходники
├── ready/               # готовые клипы (*_partNNN.mp4)
├── templates/index.html # интерфейс дашборда
├── static/              # статические ассеты
└── server.log           # лог запуска
```
